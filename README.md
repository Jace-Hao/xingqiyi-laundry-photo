# 星期衣精致洗衣衣物照片系统

基于 **Electron + Vue 3** 的洗衣店衣物拍照存档桌面应用，支持**多台电脑联网使用**：衣物按条形码建档，以摄像头最大分辨率拍照留档；管理端可管理账号权限、审计操作日志、查看全部数据并自定义照片保存路径。

## 一、快速开始

### 1. 一键安装（推荐，终端电脑使用）

1. 双击 `dist` 目录中的安装包 `星期衣精致洗衣衣物照片系统-安装包-0.1.3.exe`
2. 若出现「已保护你的电脑」提示，点「更多信息」→「仍要运行」
3. 按安装向导完成安装：可自选安装目录（默认为当前用户程序目录），完成后桌面生成快捷方式，双击即可使用

安装包已内置全部运行环境，目标电脑**无需安装 Node.js 或任何依赖**。

### 2. 源码运行（开发者）

```bash
npm install   # Electron 下载慢时先执行：$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
npm start
npm run build # 重新打包安装包
```

### 3. 首次启动：选择运行模式

首次启动会进入「运行模式设置」页，二选一：

- **作为服务端**：本电脑作为数据中枢，账号、存档、日志、照片全部保存在本机，并开启局域网服务（默认端口 17521）。保存后重启应用生效。
- **作为客户端**：本电脑作为工作站，连接已有服务端。填写服务端管理员提供的**服务器地址**（如 `http://192.168.1.10:17521`）与**连接码**，可先点「测试连接」验证。

> 之后想切换模式或查看连接信息，用管理员账号登录管理端的「系统设置」页即可。

### 4. 默认账号

| 账号 | 密码 | 角色 |
| ---- | ---- | ---- |
| admin | admin123 | 管理员（管理端） |

**首次登录后请立即修改密码**。

## 二、多电脑联网说明

### 同一局域网

服务端启动后，管理端「系统设置」页会显示**本机局域网 IP、端口、连接码**。其他电脑安装本软件后选择「作为客户端」，填入 `http://局域网IP:端口` 与连接码即可，数据实时读写服务器，无需手工同步。

**其他电脑连不上？按顺序排查：**

1. **防火墙放行（最常见原因）**：服务端电脑的 Windows 防火墙默认拦截入站连接。在服务端电脑上，右键「开始」菜单→「终端（管理员）」，执行以下命令放行端口（端口号按实际修改，默认 17521）：

   ```powershell
   netsh advfirewall firewall add rule name="星期衣衣物照片系统" dir=in action=allow protocol=TCP localport=17521
   ```

   也可以在管理端「系统设置」页点击「复制防火墙放行命令」一键复制。首次启动时若弹出防火墙授权窗口，务必勾选「专用网络」并点「允许访问」。

2. **确认服务端在线**：服务端应用必须保持运行（服务随应用启动，关闭应用窗口即停止服务）。
3. **确认同一局域网**：客户端与服务端需连接同一台路由器/交换机；在客户端电脑 `ping 服务端IP` 应能通。
4. **地址与连接码**：客户端填写的地址须为 `http://服务端IP:端口`，连接码以服务端「系统设置」页显示的为准（重置后需重新配置）。

### 跨城市 / 异地使用

数据全部集中在服务端，天然无需同步文件。跨网段打通网络推荐两种方式：

1. **异地组网（推荐）**：在服务端与每台客户端电脑安装虚拟局域网工具（如 Tailscale、ZeroTier），各设备会获得同一虚拟网段内的固定 IP，客户端填写该虚拟 IP 即可，安全性好、配置简单。
2. **内网穿透**：使用花生壳、frp 等工具，把服务端端口映射到公网地址，客户端填写映射后的地址。注意连接码务必保密，映射端口相当于把服务暴露到公网。

### 安全设计

- 客户端与服务端间所有请求必须携带**连接码**，错误连接码直接拒绝
- 登录采用**会话令牌**机制，支持多台电脑同时登录；账号停用/删除后其所有会话立即失效
- 密码使用 scrypt 加盐哈希存储；客户端只能查看自己的存档
- 连接码可在「系统设置」中随时重置

## 三、功能说明

### 客户端（店员账号登录）

| 页面 | 功能 |
| ---- | ---- |
| 登录页 | 账号密码登录；底部「⚙️ 服务器设置」可随时修改客户端连接的服务器地址与连接码（支持测试连接，保存后立即生效） |
| 首页 | 今日/累计存档统计、最近存档、快捷入口 |
| 衣物拍照 | 进入页面自动聚焦条码框，**扫码后自动进入拍摄状态**（无需点击）；摄像头按**最大分辨率**取景并启用连续自动对焦/近距对焦，减少虚焦；**空格 = 拍照**、**回车 = 保存**；扫一次码可连续拍多张，右侧实时显示缩略图队列，保存后全部存档并自动编号；照片按**条码文件夹**保存，文件名为**拍摄时间（精确到分钟）**，同一分钟内多张自动加序号 |
| 记录查询 | 按条形码精确查询、关键词/日期筛选；每张卡片显示条码、**编号**与**拍摄时间** |
| 设置 | 账号信息、修改密码 |

### 管理端（管理员账号登录）

| 页面 | 功能 |
| ---- | ---- |
| 数据总览 | 账号数、存档数、今日新增、最近存档与日志 |
| 用户与权限 | 增删改账号、停用/启用、角色与拍照/查询权限开关、重置密码 |
| 操作日志 | 查询所有账号的登录与操作记录，按账号/操作类型/关键词/日期筛选 |
| 数据查看 | 查看所有账号的衣物存档（条码+编号+拍摄时间），按账号筛选；支持**勾选批量删除** |
| 系统设置 | 服务端口、连接码（可重置）、**照片保存路径**（修改时自动迁移现有照片，冲突时拒绝覆盖）、**版本与更新**（查看当前版本、手动检查更新、打开服务端更新文件夹） |

### 批量删除

客户端「记录查询」与管理端「数据查看」页支持勾选多张卡片（或全选本页）后一键批量删除；客户端账号只能删除自己存档的记录，批量删除操作会写入日志。

### 版本与更新

- 当前版本：见 `package.json` 的 `version`（现为 0.1.3），侧边栏底部也会显示；各版本变更内容见 `CHANGELOG.md`
- **更新分发（GitHub Releases）**：新版本安装包发布到项目的 GitHub Releases，应用启动与点击「检查更新」时会自动请求 Releases 接口，发现更高版本即在界面顶部提示，点「前往下载」可直接打开下载页获取最新安装包
- **备用机制（更新文件夹）**：无法访问 GitHub 的环境（如纯内网门店）自动回退为原有机制——把带版本号的安装包放入服务端更新文件夹 `%APPDATA%\星期衣精致洗衣衣物照片系统\updates\`，各客户端/服务端启动时自动扫描并提示
- 发布新版本流程：`npm run build` 打包 → 到 GitHub 仓库创建 Release（标签如 `v0.2.0`）→ 上传 `dist` 目录中的 `.exe` 安装包 → 各终端应用检查更新即可收到提示

> 注意：`main/main.js` 顶部的 `GITHUB_REPO` 与 `package.json` 中的 `repository` 字段需替换为实际的 GitHub 仓库地址。

## 四、数据存储位置

数据保存在服务端电脑的用户数据目录下：

```
%APPDATA%\星期衣精致洗衣衣物照片系统\
  ├── data\config.json     运行模式、端口、连接码、照片路径等配置
  ├── data\users.json      账号数据
  ├── data\records.json    存档记录（条形码索引）
  ├── data\logs.json       操作日志
  ├── data\sessions.json   会话令牌
  ├── photos\              衣物照片（可在管理端「系统设置」中改到任意目录）
  └── updates\             服务端更新文件夹（放入带版本号的新安装包即可推送更新提示）
```

## 七、常见问题

**Q：客户端连不上服务器？**
A：绝大多数情况是服务端防火墙未放行端口，见「二、多电脑联网说明 → 同一局域网」的排查步骤；也可先在客户端启动设置页用「测试连接」定位问题。

**Q：扫码枪怎么用？**
A：扫码枪相当于键盘输入，光标停在「衣物条形码」输入框时扫码即可自动填入。

**Q：拍照有哪些快捷键？**
A：在拍照页，**空格键**拍摄一张（可连按多张连续拍摄），**回车键**把已拍的全部保存；光标在输入框内时快捷键不生效，避免误触。

**Q：修改端口/模式后要重启吗？**
A：端口修改会自动重启服务立即生效；切换运行模式（服务端↔客户端）需重启应用。

**Q：照片文件可以直接备份吗？**
A：可以。照片是独立的 JPG 文件，备份照片目录 + `data` 目录即完成全量备份。
