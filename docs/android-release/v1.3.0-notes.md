## 星期衣衣物照片 · Android 移动端 v1.3.0

桌面端（Electron + Vue 3）的移动伴侣 App，把**拍照录入、订单查询、日志/用户管理、离线补传**搬到手机上，复用同一套后端 HTTP 接口与权限模型。

### 安装包

| 文件 | 体积 | 说明 |
|---|---|---|
| `星期衣衣物照片-v1.3.0-release.apk` | 2.8 MB | 正式签名 + R8 混淆压缩，推荐安装 |
| `星期衣衣物照片-v1.3.0-debug.apk` | 20 MB | 调试包，包名带 `.debug` 后缀，可与正式版共存 |

- 最低系统：**Android 8.0**（minSdk 26）；目标 API 34
- 包名：`com.xingqiyi.laundryphoto`，版本 `1.3.0 (10300)`

### 使用前提

移动端与桌面端是**同一后端的两个前端**，首次打开需填写：
1. **服务器地址**：桌面端电脑的局域网地址，如 `http://192.168.1.10:17521`
2. **连接码**：桌面端「系统设置」中查看
3. **账号 / 密码**：桌面端已有账号，权限按角色自动区分

手机与桌面端电脑需在同一局域网（或通过组网/VPN 互通）。

> 桌面端需 ≥ v1.3.0 才能启用原始上传通道与「改备注」；**老服务端会自动降级**为 base64 上传并隐藏改备注入口，其余功能不受影响。

### 主要能力

- **离线优先**：服务器不可达时照片先落本机队列，联网后由 WorkManager 自动补传，失败分级重试
- **唯一登录**：同一账号异地登录会把本机顶下线，App 自动退回登录页并提示
- **条码纠错**：扫码枪近形误读（O/0、I/1）预警与相似条码提示，避免同一件衣物被拆成两个档案
- **深色模式**：跟随系统 / 浅色 / 深色三档，Android 12+ 支持动态取色
- 照片经 `FileProvider` 分享，不申请任何存储权限

### 已知限制

- 仓库路径含中文时构建需在 `gradle.properties` 启用 `android.overridePathCheck=true`（本仓库已配置）
- 单元测试需在纯英文路径下运行（Gradle 测试 JVM 在非 ASCII 路径下无法加载测试类）
