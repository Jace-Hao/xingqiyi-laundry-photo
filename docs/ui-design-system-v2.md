# 星期衣精致洗衣 · 衣物照片系统 UI 设计体系 v2.0

> 交付日期：2026-10-07 · 设计稿画布：`ardot.tencent.com/file/733839930085554`
> 定位：**从零重建**，不沿用现有「墨绿 × 黄铜 × 纸白」的任何色值、字体、布局与组件结构。

---

## 〇、产品定位与使用场景（设计依据）

**产品**：洗衣门店「衣物拍照存档」系统 —— 扫码建档、连拍存证、多机协同、照片查询导出。

| 场景 | 频次 | 环境约束 | 设计含义 |
|---|---|---|---|
| **收衣拍照**（扫码→连拍→保存） | 极高，单日上百次 | 前台站立、顾客排队、时间压力 | 单焦点界面，一屏一个主行动；空格拍照/回车保存，键盘优先 |
| **查证取衣**（按条码找照片） | 高，顾客在场等待 | 需秒级定位 | 条码号是视觉锚点，等宽字体；照片网格扫读优先于表单筛选 |
| **导出归档**（当日表格/按日期） | 中，每日 1–2 次 | 批量、需等待 | 进度可见、可取消；导出范围回显 |
| **管理配置**（账号/权限/保留期） | 低 | 高风险、易误操作 | 高危操作二次确认 + 试算；分区卡片而非长表单 |

**用户与设备**：店员（拍照/查询）、门店管理员、系统管理员。桌面 Windows 1366–1920；移动端 Android 360–430。门店柜台白炽光，屏幕常有反光。

## 一、整体框架

### 1.1 导航方式：左侧固定侧边栏（240px）+ 页面顶栏（64px）

```
┌────────┬──────────────────────────────────────────────┐
│        │ 顶栏 64px：页面标题 · 全局搜索 · 状态胶囊 · 用户 │
│ 侧边栏  ├──────────────────────────────────────────────┤
│ 240px  │                                              │
│        │              内容区（独立滚动）                  │
└────────┴──────────────────────────────────────────────┘
```

**为什么不用顶部导航**：页面多（8 个）、按角色裁剪后仍有 4–7 个入口，且是长时间驻留的工具软件。侧边栏让「当前位置」永远可见，顶栏留给全局状态。

**侧边栏结构（按角色裁剪）**

```
[品牌区] Logo 32×32 + 星期衣 / 精致洗衣 · 衣物照片
[工作区] 工作台 · 衣物拍照 · 记录查询          ← 全角色
[门店]   数据总览 · 操作日志                  ← 门店管理员及以上
[账户与帮助] 设置 · 操作手册
──────── 底部固定 ────────
v1.3.0 · 服务端模式        收起侧栏
```

- 侧边栏 240px，可折叠为 64px 图标条（状态记忆，默认展开）；折叠时图标下保留 11px 文字，**不纯靠图标**。
- 选中态：底 `#EEF1FE` + 文字 `#2C49C4` + 图标 `#3557E0`，8px 圆角；无加粗动画。
- 顶栏（左→右）：页面标题 H2 20/28 · 弹性留白 · 全局搜索 300px · 连接状态胶囊 · 主题切换 · 用户（头像 32 + 姓名/角色两行）。

### 1.2 页面信息层级

| 层级 | 元素 | 规则 |
|---|---|---|
| L1 骨架 | 侧边栏 / 顶栏 | 白底，不随内容滚动 |
| L2 区块 | 卡片（圆角 12 · 描边 1px `#E9EDF1` · 内边距 20） | 一屏 2–4 个区块，区块间距 24 |
| L3 卡片内 | 标题 16/24 Medium + 正文 14/22 | 标题与正文间距 6 |
| L4 元信息 | 12/16 `#68727F` | 只承载"谁/何时/何地" |

### 1.3 栅格与留白

- 12 栅格，gutter 16；页面边距 24（<1600）/ 32（≥1600）；内容最大宽 1440，**左对齐**（工具型软件不居中，居中会在超宽屏上拉开侧边栏与内容）。
- 三区布局（≥1440）仅详情页允许：侧边栏 240 + 内容 + 右侧信息面板 360。
- 留白节奏：区块间 24 / 32；卡片内 20；控件间 8 / 12。**宁可空，不可挤。**

## 二、核心页面布局与功能职责

### 2.1 主页面「工作台」

**一句话**：告诉店员现在该干嘛，并给出唯一的大按钮。

```
问候行：下午好，李店员            2026 年 10 月 7 日 · 星期三
┌─ 主行动卡（高 132，白卡）──────────────────────────┐
│ 开始收衣拍照                              [进入拍照台] │
│ 扫码后自动进入拍摄 · 空格拍照 · 回车保存   [直接查订单]  │
└──────────────────────────────────────────────────┘
[今日收衣 128 件] [本月累计 2846 件] [待取件 37 单·最长滞留5天]
最近收衣                                 查看全部 128 条 →
[照片卡 ×10：缩略图 124 + 条码等宽 + 时间/张数/录入人]
```

- 指标卡：标签 13/20 `#68727F`，数值 32/40 等宽 SemiBold，变化说明 12/16（正向绿 `#12603F` / 告警琥珀 `#8A5200`）。
- **一屏一个主行动**：「进入拍照台」是唯一主按钮；「直接查订单」为次按钮。
- 照片卡是点击目标而非装饰：整卡可点进详情，hover 才出现主色描边。

### 2.2 列表页「记录查询」

**一句话**：按条码/日期找到那批照片。

```
筛选栏（白卡，一行，控件高 40）
[条码输入框·聚焦态 2px 主色描边] [日期范围] [录入人▾]      [重置][查询]
共 128 条记录 · 第 1/13 页              ☐全选本页 [导出照片][下载当日表格][批量删除]
[照片网格 5 列 × N 行]
                    [上一页][1][2][3]…[13][下一页]
```

- **条码框自动聚焦**（沿用现有行为）；聚焦态 2px 主色描边，不用阴影。
- 筛选与结果之间放「结果条」：左侧计数（等宽字体），右侧批量操作。
- **批量删除在未勾选时禁用**（灰 `#F4F6F8` 底 + `#9AA3AF` 字），勾选后才点亮为危险描边——防止误点。
- 网格 5 列（1440）/ 6 列（≥1600），缩略图比例 16:11，圆角 4。
- 分页居中，页码等宽字体；总页数 ≤ 1 时整行隐藏。

### 2.3 详情页「订单照片详情」

**一句话**：看大图 + 拿到这一单的全部信息。

```
左（fill）：看图区（白卡）主图 fill_container + 缩略图条 6×96×64（选中 2px 主色描边）
右 360px：信息面板（白卡，内边距 20，纵向 gap 14）
  条码 XQY202610070031（18/26 等宽 SemiBold）
  [4 张照片] [已同步] [含时间水印]
  ── 录入人 / 所属门店 / 拍摄时间 / 存储路径（键左值右，等宽值）──
  [下载原片]（主按钮）
  [导出该订单全部照片]（次按钮）
  [删除记录]（危险描边，与其他按钮隔开）
```

- 键盘 ←/→ 切图、Esc 关闭（沿用现有行为，含输入法组合态防护）。
- 删除按钮必须与另两个按钮**视觉隔离**（间距 12 + 危险色），不与下载并排等宽同高。
- 移动端：全屏灯箱，信息面板自底部上滑。

### 2.4 设置页

**一句话**：低频但高风险，用「左侧二级导航 + 右侧分区卡片」组织。

```
左侧二级导航 200px（sticky）      右侧内容（每分区一张白卡）
· 账户与安全                      [账户与安全] 修改密码 / 所属门店（只读）
· 外观                            [外观]      主题：跟随系统/浅色/深色（三选一卡）
· 存储与同步（仅服务端）            [存储与同步] 照片保存路径 / 订单保留期（含试算）
· 版本与更新                      [版本与更新] 当前版本 / 检查更新 / 强制推送
· 关于                            [危险区·红描边独立卡] 数据保留期 / 退出登录
```

- 表单行：标签 160px 左对齐 + 控件右侧，行距 24。
- **危险区独立成卡**（红描边 `#F0C6C2`），与其他设置物理隔离。

## 三、视觉规范

### 3.1 配色

**主色 Primary · 靛蓝**（仅用于可行动元素，不用于装饰；面积 < 5%）

| 档 | 色值 | 用途 |
|---|---|---|
| 50 | `#EEF1FE` | 选中底 / 信息底 |
| 200 | `#C7D0FA` | 描边、悬浮 |
| **500** | **`#3557E0`** | 主按钮、链接、选中（白字对比 5.9:1）|
| 600 | `#2C49C4` | Hover |
| 700 | `#243CA3` | Active |

**语义色**：一律「底色 + 边框 + 文字色」三件套，色块不单独承载含义。

| 语义 | 主色 | 底色 | 文字色（对比度） | 用途 |
|---|---|---|---|---|
| 成功 | `#1A7F5A` | `#E7F5EF` | `#12603F`（7.6:1）| 已同步、保存成功 |
| 警告 | `#B26A00` | `#FFF6E6` | `#8A5200`（6.4:1）| 离线待同步、磁盘告急 |
| 危险 | `#C8382F` | `#FDECEA` | `#A32B23`（7.1:1）| 删除、不可逆操作 |
| 信息 | `#3557E0` | `#EEF1FE` | `#2C49C4` | 与主色同源，不引入第四色相 |

**中性灰阶 11 级**（承载 95% 界面）：
`#FFFFFF` `#FAFBFC` `#F4F6F8` `#E9EDF1` `#D8DEE5` `#B9C2CC` `#8A95A3` `#68727F` `#4C5563` `#38404C` `#252B35` `#15191F`

**文本三级**：主 `#15191F`（≈16:1）· 次 `#4C5563`（≈8:1）· 辅 `#68727F`（4.9:1，AA 达标）。禁用态 `#9AA3AF`（豁免对比度要求，但仍需可辨识）。

### 3.2 字体层级

| 层级 | 规格 | 用途 |
|---|---|---|
| Display | 32/40 · 600 | 仅首页大数字 |
| H1 | 24/32 · 600 | 页面标题 |
| H2 | 20/28 · 600 | 区块标题 |
| H3 | 16/24 · 500 | 卡片标题 / 表格主文本 |
| Mono | 15/22 · 500 | **条码、单号、时间**（强制等宽）|
| Body | 14/22 · 400 | 默认正文 |
| Body-S | 13/20 · 400 | 表格次要列、筛选说明 |
| Caption | 12/16 · 400 | 元信息 |

- 字族：`"Noto Sans SC", "PingFang SC", "Microsoft YaHei UI", system-ui, sans-serif`；数字/条码 `"JetBrains Mono", "Roboto Mono", Consolas, monospace`。
- 字重只用 400/500/600；行高 = 字号 × 1.5（标题 1.3）。**一屏内不超过 3 个层级。**

### 3.3 间距 / 圆角 / 阴影

- **间距刻度**：`2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64`。卡片内边距 16（紧凑）/ 20（默认）/ 24（区块）；区块间距 24–32；页面边距 24（1366）/ 32（≥1600）。
- **圆角**：`2 · 4 · 6 · 8 · 12 · 16 · 999`。控件 8 · 卡片 12 · 弹层 16 · 标签 999 · **照片缩略图只给 4**（避免圆角吃掉画面）。
- **阴影（克制，4 级）**：xs `0 1 2 ·6%`；sm `0 1 3 ·8%`；md `0 4 12 ·10%`（仅悬浮卡片）；lg `0 12 32 ·14%`（仅弹层）。**静态卡片一律无阴影**，靠 1px `#E9EDF1` 描边分层。

### 3.4 图标风格

- 线性 stroke 2px @ 24 网格，圆头端点、圆角连接，单色 `currentColor`；尺寸 16 / 20 / 24（按钮内 16、导航 20、页面级 24）。
- **导航与操作必须图文并列**，图标不单独承载语义（店员不一定认识图标）。

## 四、交互细节

### 4.1 控件状态（7 态）

| 状态 | 规则 |
|---|---|
| Default | 描边 1px `#D8DEE5`，底白 |
| Hover | 描边 `#B9C2CC` |
| Focus-visible | **2px 主色描边 + 2px 外留白**（不用阴影发光，避免门店强光下看不清）|
| Active | 底 `#EEF1FE` |
| Disabled | 底 `#F4F6F8` · 文字 `#9AA3AF` · 无描边；**必须同时给出原因** |
| Loading | 按钮内 spinner 替换文字，防重复提交 |
| Error | 描边 `#C8382F` + 下方 12/16 红字，焦点自动移到第一个错误项 |

### 4.2 空状态 / 加载 / 错误

| 场景 | 表现 |
|---|---|
| 空列表 | 线性图标 + 一句话（"本店今天还没有收衣记录"）+ **一个**行动按钮；不放插画堆砌 |
| 加载 | **骨架屏**（网格/表格占位块），不用转圈；> 3s 追加进度文案 |
| 请求失败 | 卡片内 InlineAlert（可重试）+ Toast；**不断流**，保留已加载数据 |
| 服务端失联 | 顶栏状态胶囊变琥珀「离线 · 待同步 N」，页面**继续可用**（离线拍照/查询本机缓存）；胶囊可点击查看队列 |
| 同步进行中 | 胶囊显示「同步中 x/y」，完成 Toast |
| 删除 | 二次确认对话框，按钮写**动词**（"删除这 3 条记录"），不写"确定" |

### 4.3 深浅色模式

跟随系统，可在设置覆盖（跟随系统 / 浅色 / 深色），**状态记忆**。深色**不是简单反相**：

| 令牌 | 浅色 | 深色 |
|---|---|---|
| 应用底 | `#F4F6F8` | **`#0F1216`** |
| 卡片 | `#FFFFFF` | **`#171B21`** |
| 弹层 | `#FFFFFF` | **`#1E232B`** |
| 描边 | `#E9EDF1` | **`#2A313B`** |
| 主色 | `#3557E0` | **`#7C93FF`**（提亮一档，6.2:1）|
| 正文 | `#15191F` | **`#E8ECF1`** |
| 次文本 | `#4C5563` | **`#A2ACBA`** |

- 分层靠「底色深浅 + 1px 描边」，不用阴影；照片一律保持原样不叠色。
- 语义色在深色下也需提亮并重新校验对比度（成功 `#4ADE9E` / 警告 `#F0B429` / 危险 `#FF7A6B`）。

### 4.4 可访问性（硬性要求）

- 正文级文字对比度 ≥ 4.5:1；大字（≥18.66px Bold 或 24px）≥ 3:1。本文所有色值均已核算。
- **焦点永远可见**（focus-visible 2px 环），键盘全流程可达：Tab 遍历、Enter 触发、Esc 关闭。
- 点击目标桌面 ≥ 32px（主按钮 44px）、移动 ≥ 44px；**色不单独承载含义**，语义色必须配文字或图标。
- 快捷键必须放行输入法组合态：`if (e.isComposing || e.keyCode === 229) return;`（现有 v1.1.8 修复必须保留）。

## 七、可用性与响应式审查

针对现有 v1.2.x 实现，按严重度排序：

| # | 问题 | 严重度 | 建议 |
|---|---|---|---|
| 1 | **批量删除按钮在无勾选时仍可点**，点后才报"未选择" | 高 | 无勾选时禁用 + tooltip 说明；勾选后才点亮 |
| 2 | 顶栏无全局状态；离线/同步要进设置页才能看到 | 高 | 状态常驻顶栏（胶囊），离线时页面保持可用 |
| 3 | 查询页筛选与结果之间缺"结果条"，勾选状态与列表视觉上断开 | 中 | 增加结果条：左计数、右批量操作，与网格同属一个卡片组 |
| 4 | 分页器页码用非等宽字体，"1/13"扫读易串行 | 中 | 页码与计数一律等宽 |
| 5 | 删除确认按钮文案是"确定"，与取消只有颜色差 | 中 | 按钮写动词："删除这 3 条记录" |
| 6 | 主色（墨绿）在门店混合光下与成功态绿易混淆 | 中 | 主色换靛蓝，与语义绿拉开色相 |
| 7 | 拍照页休眠浮层偶发遮挡条码输入框（历史 bug） | 中 | 浮层底部对齐，保留输入框可点 |
| 8 | 超宽屏（≥1920）下内容居中导致侧边栏与内容出现大空档 | 低 | 内容左对齐，最大宽 1440 |
| 9 | 表格行高偏小，戴手套难点中 | 低 | 紧凑档行高 ≥ 36，主按钮 ≥ 44 |
| 10 | 空状态无行动指引，只有一句"暂无数据" | 低 | 空状态 = 图标 + 一句话 + 一个行动按钮 |

**响应式断点**：

| 断点 | 布局 |
|---|---|
| ≥ 1440 | 侧边栏 240 + 内容（详情页可加第三区 360）|
| 1024–1439 | 侧边栏 240 + 内容，隐藏第三区 |
| 768–1023 | 侧边栏折叠为 64px 图标条 |
| < 768 | 顶部栏 + 底部 Tab（移动端 App 专用）|

现有实现以 1920 为默认，1366（门店常见最低配）下筛选栏会折行且网格只剩 3 列，扫读效率下降。建议优先验证 **1366 与 1920 两档**；平板（768–1023）折叠侧边栏即可，不必为平板做单独布局。
