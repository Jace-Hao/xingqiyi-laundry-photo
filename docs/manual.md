## 一、系统概述

星期衣精致洗衣衣物照片系统是面向洗衣店的桌面应用，用于在收衣环节对衣物拍照存档。以衣物条形码为索引建立档案，取衣时可随时调阅核对，避免衣物混淆与纠纷。

系统按门店与角色组织权限：店员在客户端拍照与查询，同一门店的账号可互相查询彼此的订单照片；门店管理员可查看本门店全部订单与操作日志；系统管理员在管理端管理账号权限、审计操作日志、查看与清理全部门店的存档数据。系统支持多台电脑联网使用，数据集中在服务端电脑。

账号角色分为四级，权限随角色固定，不再单独勾选：

| 角色 | 能做什么 |
| --- | --- |
| 系统管理员 | 查看全部与全部门店订单、设置账号与权限、查看所有门店操作日志、修改系统设置。无需分配门店 |
| 门店管理员 | 查看本门店全部订单与本门店操作日志。**只查不拍**：不能拍照录入、不能删除订单、不能管理账号与系统设置。必须分配门店 |
| 拍照账号 | 拍照录入订单，并查询本人与同门店同事的订单 |
| 查询账号 | 仅查询本人与同门店同事的订单，不能拍照录入 |

## 二、安装与启动

### 2.1 环境要求

操作系统：Windows 10 / 11（64 位）

无需安装任何其他软件：运行环境已内置在安装包中

硬件：摄像头（拍照用）、扫码枪（可选，即插即用）


### 2.2 安装步骤

把安装包 xingqiyi-laundry-photo-setup-1.1.4.exe 复制到目标电脑

双击安装包；如出现「已保护你的电脑」提示（因软件未做数字签名），点「更多信息」再点「仍要运行」

按安装向导选择安装目录（默认为当前用户程序目录），完成后桌面生成快捷方式


### 2.3 日常启动

双击桌面快捷方式即可。多台电脑使用时，为每台电脑分别安装一次；建议为每台使用电脑固定一台扫码枪与摄像头。


### 2.4 卸载

在 Windows 设置「应用 → 安装的应用」中找到本软件卸载即可。卸载不影响已保存的账号与照片数据，重装后数据仍在。


## 三、软件激活

### 3.1 激活机制

安装后首次使用需输入激活码完成激活。未激活可试用 7 天，试用到期后强制要求激活，无法继续使用。

激活码与本机机器码一一绑定，每台电脑的机器码唯一（由硬件特征派生，16 位字符）。


### 3.2 激活流程

启动程序后，登录页自动弹出「软件激活」窗口

记录本机机器码（如 ABCD-EFGH-JKLM-NPQR）

将机器码提供给管理员，由管理员使用激活码计算工具生成激活码

在激活窗口输入激活码，点击「激活」

激活成功后弹窗关闭，可正常使用。试用期内可暂不激活，但到期后将强制要求。


### 3.3 生成激活码

由**系统管理员**在命令行执行以下命令，根据客户机器码生成激活码（激活码计算工具不随公开仓库发布，需向软件维护者索取）：

node scripts/license-tool.js <机器码>

校验已有激活码是否正确：

node scripts/license-tool.js --verify <机器码> <激活码>


## 四、首次启动：选择运行模式

首次启动会进入运行模式设置页，请根据这台电脑的角色二选一。设置保存后需重启程序生效；之后如需切换，可在管理端系统设置中调整。


### 4.1 作为服务端（推荐第一台电脑选择）

本电脑作为数据中枢：所有账号、存档记录、操作日志与照片都保存在这台电脑上，并自动开启局域网服务（默认端口 17521）供其他电脑接入。

保存后界面会显示服务端口、连接码与本机局域网 IP，请抄录备用。


### 4.2 作为客户端

本电脑作为工作站，连接已有的服务端。填写管理员提供的服务器地址（形如 http://192.168.1.10:17521）与连接码，先点「测试连接」，通过后保存即可。

登录页底部也有「服务器设置」入口，客户端电脑更换服务器地址时无需重装，直接在此修改并保存即可生效。


## 五、登录与账号

### 5.1 默认账号

| 账号 | 初始密码 | 角色 |
| --- | --- | --- |
| admin | admin123 | 系统管理员（管理端） |

首次登录后请立即在设置页修改密码，并通过管理端为每位店员创建独立账号，并按门店与岗位职责分配合适的角色。


### 5.2 登录页功能

输入账号密码登录；系统管理员进入管理端，门店管理员与店员账号进入客户端界面（可见的菜单按角色不同）

**记住账号 / 记住密码**：登录框下方可勾选「记住账号」（默认勾选）与「记住密码」（默认不勾选）。勾选记住账号后，下次打开软件会自动填充最近使用的账号；点击账号输入框可从下拉中选择本机保存过的账号，下拉中会显示各账号的角色与所属门店，带 🔑 标记表示已保存密码。

密码安全说明：

- 密码经**系统凭据保护**（Windows DPAPI / macOS Keychain）加密后保存在本机，**不会明文存储**，也不会上传到服务器
- 若本机系统凭据保护不可用，「记住密码」会自动禁用并给出提示，此时仅记住账号名——系统**不会退而求其次地明文保存密码**
- ⚠️ **共用电脑请谨慎勾选「记住密码」**：开启后，任何能打开本软件的人从账号下拉中选中该账号即可直接登录。门店工位机建议只勾选「记住账号」
- 下拉中每个账号右侧的 ✕ 可单独移除该账号的保存记录；底部「清空全部保存记录」可一次性清除本机保存的全部账号与密码

底部「服务器设置」：查看当前运行模式；客户端可随时修改服务器地址与连接码，支持先测试连接再保存

展示当前版本号，提供「一键下载安装包」按钮（无需登录即可下载最新版本）


### 5.3 修改密码

各角色账号均可在「设置」页查看账号信息并修改密码；修改密码需输入原密码，新密码至少 6 位。修改密码不会改变账号的角色与所属门店。


## 六、客户端操作（店员）
<!-- roles:capture,query,storeadmin -->

### 6.1 首页

首页展示存档总数（门店管理员为「本店订单总数」）、今日新增数量与最近六条存档，并提供「衣物拍照」「记录查询」快捷入口。查询账号与门店管理员不显示拍照入口。点击任意存档卡片可查看详情。


### 6.2 衣物拍照（核心流程）
<!-- roles:capture -->

标准操作流程共三步：扫码、拍照、保存。

扫码：进入拍照页后光标自动停在条形码输入框，用扫码枪扫衣物条码（或手动输入后按回车），系统自动确认条码并进入拍摄状态，无需任何点击。

拍照：按空格键拍摄一张，可连续按空格拍多张（如正面、背面、瑕疵细节），右侧实时显示缩略图队列，每张标注序号，可单独移除或清空。

保存：按回车键或点击「保存全部」，队列中所有照片一次性存档，自动接续该条码已有的编号（第 1 张、第 2 张…），保存后条码框自动清空并重新聚焦，直接扫下一件。


#### 拍照页要点

照片按摄像头最大分辨率拍摄，取景框旁实时显示当前分辨率

拍摄时自动在照片右上角烧录拍照时间水印（年-月-日 时:分）。水印写入照片本身，导出或打印后依然可见，可作为收衣时间存证；水印字号随照片分辨率自动缩放，高分辨率下同样清晰

已启用连续自动对焦与近距对焦，减少虚焦

备注栏可填写已有瑕疵、特殊洗护要求等信息（可选），同一批次照片共用该备注

扫码枪相当于键盘输入：请确保光标在条形码输入框内再扫码


#### 快捷键

| 按键 | 作用 | 备注 |
| --- | --- | --- |
| 空格 | 拍摄一张照片 | 可连续按，拍多张 |
| 回车 | 保存全部 / 确认条码 | 输入框内为确认条码，输入框外为保存 |


### 6.3 记录查询

支持按条形码精确查询，也可按关键词（条码、备注、录入人、门店名模糊匹配）与日期范围组合筛选。每张卡片显示条码、编号、拍摄时间；点击卡片查看详情大图。

可见范围：拍照账号与查询账号可看到本人以及**同一门店**其他账号录入的订单（门店由系统管理员分配）；门店管理员可看到本门店全部订单；未分配门店的账号只能看到本人订单。属于同事录入的订单会标注录入人，门店管理员查看时还会显示归属门店。

批量删除：勾选卡片左上角的勾选框（或点「全选本页」），再点「批量删除」。删除前会弹出确认框，删除后照片文件一并删除且不可恢复，请谨慎操作。**只能删除本人录入的记录**：同门店同事的订单可查看与导出但不能删除；门店管理员与查询账号不录入订单，因此不显示勾选框与批量删除按钮，详情中会提示「仅可查看与导出，不可删除」。

按订单号批量下载照片：勾选记录后点「按订单号批量下载」，导出勾选记录涉及的条码。未勾选则导出当前列表全部条码。选择保存目录后，照片按条码分文件夹保存，文件名为「拍摄时间_第N张.jpg」。

按日期导出照片：选择日期范围后导出，系统自动按条码分文件夹归档，并附带一张归档表格。表格按**订单（条码）汇总**，每个条码一条记录，包含三列：条码、照片数量、归档文件夹位置；照片本身仍全部导出到对应条码文件夹中。


### 6.4 设置

展示本账号的角色、所属门店（由系统管理员分配，本人只读不可修改）、权限开通情况、创建时间与最近登录时间，并可修改登录密码。

底部「版本与更新」卡片展示当前版本号，支持一键下载安装包，实时显示下载进度（已下载/总大小、百分比），支持取消下载。


## 七、管理端操作（系统管理员）
<!-- roles:sysadmin,storeadmin -->

### 7.1 数据总览
<!-- roles:sysadmin -->

展示账号总数、启用中账号数、存档照片总数、今日新增，以及**四级角色的账号构成**、最近存档与最近操作日志（含操作来源 IP），便于快速掌握各门店情况。


### 7.2 用户与权限
<!-- roles:sysadmin -->

新增账号：用户名（3-20 位字母数字下划线）、姓名、角色、所属门店、初始密码（至少 6 位）

角色分配：从四级角色中选择（系统管理员 / 门店管理员 / 拍照账号 / 查询账号），弹窗内会显示该角色的能力说明。**权限由角色固定决定，不能单独勾选**，因此不会出现「门店管理员可拍照」这类与角色定义矛盾的账号；账号列表以只读方式展示每个账号的实际权限。

门店分配：填写门店名称即可归属该门店（也可从已用过的门店名中直接选择，避免名称写得不一致）。同一门店的账号可互相查询订单照片，**门店名称必须完全一致**才会归为同店。系统管理员无需分配门店（可查看全部记录）；**门店管理员必须分配门店**，否则会提示并拒绝保存。

门店变更与历史订单：调整某账号的门店后，其**历史订单仍归属原门店**（衣物实际收存于原门店），只有此后新增的订单才归属新门店。账号编辑页会提示这一点。

停用 / 启用：停用后该账号立即无法登录，已登录的会话也会即时失效

重置密码：编辑账号时填写新密码即可重置；删除账号前请确认其存档已交接。账号列表会显示每个账号的角色、所属门店与权限，未分配门店的账号标记为「未分配」，门店管理员若缺门店会标记为「未分配（异常）」。


### 7.3 操作日志

记录所有账号的登录（含失败）与关键操作，每条日志显示来源 IP 与账号角色。可按账号、操作类型、关键词、日期范围、IP 地址筛选。发生纠纷时可据此追溯操作人与时间。

可见范围：**系统管理员**可查看并筛选所有门店账号的日志；**门店管理员**只能查看本门店账号的日志（侧边栏菜单名为「本店日志」，页面标题会说明范围），看不到其他门店与系统管理员的操作记录。拍照账号与查询账号无权查看操作日志。

「操作类型」筛选项由系统统一提供，与日志中实际出现的类型一致（包含「新增条码」「新增存档照片」等），不会出现选了某类型却查不到任何记录的情况。


### 7.4 数据查看

查看存档数据，可按所属账号、**所属门店**、条形码、关键词、日期筛选；支持查看详情与批量删除。

可见范围：**系统管理员**可查看全部与全部门店的存档，并可删除任意账号的记录；**门店管理员**通过客户端的「本店订单」页查看本门店全部订单，可查看与导出但不能删除。

支持「按订单号批量下载照片」与「按日期导出照片」，操作方式与客户端相同，但系统管理员可导出任意账号、任意门店的存档照片，门店管理员的导出范围限本门店。


### 7.5 系统设置
<!-- roles:sysadmin -->

#### 服务信息

查看运行模式、本机局域网 IP、连接码；客户端模式可查看已配置的服务器地址。

修改服务端口后自动重启服务；重置连接码后所有客户端需使用新码重新配置。


#### 照片保存路径

可修改照片保存目录，保存时自动把现有照片迁移到新目录（含条码子文件夹）；若目标目录已存在同名文件会中止迁移并提示，避免覆盖。


#### 版本与更新

展示当前版本号与检查结果，可手动点击「检查更新」，支持一键下载安装包。服务端管理员可一键打开「软件更新」文件夹（位于软件安装目录下，用于内网环境分发安装包）。


#### 强制推送安装包

**系统管理员**可在「系统设置」中开启「强制推送」并选择待推送的安装包文件（门店管理员与其他角色无此权限）。开启后，客户端下次登录时自动检测并弹窗提示安装，确保所有终端及时升级。


#### 开机自动启动

**系统管理员**可在「系统设置 → 开机自动启动」中开启，用于避免门店断电或重启后服务没有自动起来、导致各客户端连不上。

行为说明：

- 开启后，本机登录 Windows 时自动启动软件，并**静默驻留系统托盘**（不弹出窗口、不打断开机流程），持续为客户端提供照片服务
- 需要操作界面时，点托盘图标（或托盘菜单的「显示主窗口」）即可打开
- **仅服务端模式可开启**：客户端为工位机、无需常驻。若当前是客户端模式，该开关会被禁用并说明原因；需先切换为服务端模式
- 本机从服务端**切换为客户端模式时，会自动取消已设置的开机自启**，避免工位机变成每次开机常驻
- 软件为**单实例**运行：开机自启后再次双击桌面图标，不会启动第二个程序，而是把已在运行的窗口唤到前台（避免两个程序争抢同一服务端口）
- 若系统组策略禁止设置登录项，界面会如实提示设置未生效，不会显示为「已开启」


#### 订单数据保留期（超时自动删除）

**系统管理员**可在「系统设置 → 订单数据保留期」中设置订单数据的保存期限，超期订单及其照片会被自动清理，用于控制长期累积占用的磁盘空间。

⚠️ **这是不可逆删除**：超期订单的记录与照片文件会被永久移除，无法恢复。请务必先用「试算」确认影响范围，并做好备份（见「数据存储与备份」）。

设置说明：

- **默认关闭**：未设置保留期时，系统在任何情况下都不会自动删除数据
- **最小 1 天**：不接受 0 或负数——「保留 0 天」等于清空全部订单，已被显式拒绝
- 删除范围：按订单**录入时间（createdAt）**判定，超过保留天数的订单，连同其全部照片文件一并删除
- 首次开启或缩短保留期时，界面会弹出确认框提示影响面（延长或取消则不弹）
- 保存设置**不会立即删除**数据，自动清理按计划在后台执行

清理时机与安全防护：

- **仅服务端模式执行**；客户端模式下不会清理（数据以服务端为准）
- 软件启动后延迟执行一次，之后周期性检查
- **全删熔断**：若某次清理将删除**全部**订单（例如系统时钟异常跳到未来，导致所有订单都判定为超期），自动清理会**拒绝执行并告警**，避免误删全部数据。此时请核对电脑系统时间后重试
- 每次自动清理都会记入操作日志（动作类型「自动清理过期订单」），写明清理条数与保留期限
- 门店管理员与其他角色无此权限，界面不显示该设置


#### 内置操作手册

软件已内置操作手册（侧边栏「📖 操作手册」，所有角色均可见）：

- 左侧目录可点击跳转到对应章节，右侧为正文
- **章节按当前账号角色自动裁剪**：例如拍照账号不会看到「用户与权限」「系统设置」等章节；系统管理员可查看全部章节，便于指导门店与排障
- 若内置手册版本与当前软件版本不一致，页面顶部会给出提示，此时以实际界面为准
- 手册内容随软件一同打包，**离线环境下也可查阅**，无需联网或另找文档


## 八、多电脑联网使用

系统采用「服务端 + 客户端」架构，数据全部集中在服务端，各客户端实时读写，无需手工同步文件。


### 8.1 同一局域网

选定一台电脑作为服务端（建议固定不移动的电脑），保持程序运行

在服务端管理端「系统设置」页抄录本机局域网 IP、端口与连接码

其他电脑安装本程序，首次启动选择「作为客户端」，填入上述地址与连接码，测试通过后保存

若 Windows 防火墙提示，请允许程序通过专用网络

防火墙放行命令（服务端管理员终端执行，默认端口 17521）：

netsh advfirewall firewall add rule name="星期衣衣物照片系统" dir=in action=allow protocol=TCP localport=17521

也可在管理端「系统设置」页点击「复制防火墙放行命令」一键复制。


### 8.2 跨城市 / 异地使用

数据集中在服务端的特性使异地使用无需同步文件，只需打通网络，推荐两种方式：

异地组网（推荐）：在服务端与每台客户端安装虚拟局域网工具（如 Tailscale、ZeroTier），各设备获得同一虚拟网段的固定 IP，客户端填写虚拟 IP 即可，安全性好、配置简单。

内网穿透：使用花生壳、frp 等工具把服务端端口映射到公网地址，客户端填写映射后的地址。注意连接码务必保密，映射端口相当于把服务暴露在公网。


### 8.3 安全设计

客户端与服务端间所有请求必须携带连接码，错误连接码直接拒绝

登录采用会话令牌机制；**同一账号具有唯一登录性，不可同时在多地登录**（详见下方说明）；账号停用/删除后其所有会话立即失效

密码使用 scrypt 加盐哈希存储；客户端可查看本人及**同门店**账号的存档（未分配门店的账号仅可见本人存档）

连接码可在「系统设置」中随时重置


#### 账号唯一登录

一个账号同一时间只能在一台电脑上处于登录状态：

- 在某台电脑登录某账号后，该账号此前在其他电脑的登录会**立即失效**
- 被顶下线的电脑会弹出提示「账号已在其他设备登录，当前会话已失效，请重新登录」，并退回登录页；提示中会写明顶下线的登录时间与来源 IP，便于确认是谁在使用
- 这不是密码错误，无需重置密码；若确实需要两台电脑同时使用同一账号，请由系统管理员为每台电脑建立独立账号（便于日志追溯到人）
- **离线登录不受此限制**：服务器失联时客户端用本机镜像登录，不经服务端签发会话，因此不会被顶下线；服务器恢复并重新登录后，离线期间录入的数据会正常补传


## 九、离线模式（客户端灾难恢复）

### 9.1 触发条件

客户端模式下，当服务器因网络故障、服务端程序关闭等原因无法连接时，系统自动进入离线模式。


### 9.2 离线可用功能

使用本机缓存的账号信息离线登录（需此前成功登录过一次）

正常进行衣物拍照与存档，操作进入本地离线队列

查询本机缓存的历史存档记录

界面顶部显示「离线状态」提示条，告知当前服务器不可用，数据暂存本机。


### 9.3 自动同步

服务器恢复上线后，系统自动将离线期间的存档逐条回传同步到服务端，界面顶部显示同步进度。同步完成后离线状态提示消失，恢复正常运行。

同步过程中若某条记录因照片丢失等原因失败，该条会被跳过，不会阻塞后续同步。

**离线数据一定会上传**：离线期间录入的存档保存在本机待同步队列中，只有在服务器确认接收成功后才会从队列移除，因此不会因为中途断网、程序关闭或登录会话失效而丢失。即使同一账号此时已在其他电脑登录，本机重新登录后仍会把离线数据补传上去——这是刻意的设计，避免唯一登录导致门店离线期间收的衣物没有存档。

若同步时提示「登录会话已在其他设备失效，请重新登录后再同步离线存档」，说明本机此前的登录已被顶下线；重新登录即可继续补传，**队列中的数据不会被清空**。


## 十、数据存储与备份

### 10.1 存储位置

所有数据保存在服务端电脑的用户数据目录下：


| 位置 | 内容 |
| --- | --- |
| data\config.json | 运行模式、端口、连接码、照片路径等配置 |
| data\users.json | 账号数据 |
| data\records.json | 存档记录（条形码索引） |
| data\logs.json | 操作日志（含来源 IP） |
| data\sessions.json | 会话令牌 |
| data\offline-queue.json | 客户端离线待同步队列 |
| photos\ | 衣物照片（可在系统设置中改到任意目录） |

完整路径形如 %APPDATA%\星期衣精致洗衣衣物照片系统\，可在文件资源管理器地址栏粘贴 %APPDATA% 快速定位。

更新文件夹（「软件更新」）位于软件安装目录下，不在用户数据目录；更新下载、内网分发与强制推送共用该目录。


### 10.2 照片命名规则

照片按条形码建立子文件夹，文件名为拍摄时间（精确到分钟），例如：

photos\XQ20260902001\202609021545.jpg

同一分钟内拍摄的多张自动追加序号（202609021545-2.jpg），不会相互覆盖。该结构便于直接浏览与备份照片文件。


### 10.3 备份建议

定期整体备份照片目录与 data 目录（可压缩后存入移动硬盘或网盘）

照片目录较大时，可先通过「系统设置」把照片保存路径改到独立磁盘，再针对该磁盘做备份

程序卸载或删除不会影响已保存的数据；重装后数据仍在原位置
