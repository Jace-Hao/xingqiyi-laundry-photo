# 桌面端 v1.2.4 发布说明

**一句话**：本版把「手机 App 自己更新」的后台能力补齐了。管理员只要把手机安装包丢进「软件更新」文件夹，门店所有手机就能在手机上直接更新，不用再一台台用数据线拷。

| 项目 | 值 |
|---|---|
| 版本 | v1.2.4 |
| 配套 | 移动端 **v1.1.0** |
| 上一版 | v1.2.3 |

---

## 一、这版新增了什么

### 手机端可以自己查更新了

之前手机 App 没有任何自更新能力，只能人工拷 APK。本版起，手机登录后可以向桌面端查询「有没有新的手机安装包」，包括版本号、大小、更新说明。

### 「软件更新」文件夹里放 `.apk` 会被认出来

这是本版最直观的变化。以前这个文件夹只认电脑安装包（`.exe` / `.zip` / `.msi`），现在 `.apk` 也会被识别。

**两种安装包可以放在一起，互不干扰：**

| | 电脑安装包 | 手机安装包 |
|---|---|---|
| 文件名示例 | `xingqiyi-laundry-photo-setup-1.2.4.exe` | `xingqiyi-laundry-photo-android-1.1.0.apk` |
| 谁来取 | 桌面端自己 | 手机 App 自己 |
| 结果 | 桌面端永远只看到 `.exe` | 手机端永远只看到 `.apk` |

**不会串台**：文件夹里同时放 `1.2.4.exe` 和 `1.1.0.apk` 时，桌面端检查更新仍然提示 `1.2.4`，手机端检查更新提示 `1.1.0`，互不干扰。这条已纳入自动化验证，每次发布都会跑。

### 手机端的强制推送现在能推手机包了

以前管理员在「系统设置 → 强制更新」的文件下拉框里根本选不到 `.apk`，想推手机包也推不了。本版起下拉框会列出 `.apk`，勾选后手机端下次打开会进入必须更新的流程。

> ⚠️ **一个需要留意的副作用**：桌面端那个下拉框现在**也会把 `.apk` 列出来，而且没有加「（安卓包）」标签**。请留意别把手机包装当成电脑安装包勾错。

### 更新说明：放个同名文件就行

以前要给手机端写更新说明，得手工建文件。现在**在旁边放一个同名的 `.md` 文本文件**（文件名把 `.apk` 换成 `.md`），内容就会显示在手机端的更新弹窗里。

- 文件名必须严格对应：APK 是 `xxx-1.1.0.apk`，说明文件就是 `xxx-1.1.0.md`；
- 没放也不影响更新，手机端会显示「管理员没有写这次的更新说明」；
- 说明太长会被截断（约 2000 个字），建议只写 3～5 条要点。

## 二、管理员操作指南

### 部署一次新版本

1. 把**电脑安装包** `.exe` 放进「软件更新」文件夹 —— 这条和以前一样；
2. 把**手机安装包** `.apk` 也放进同一个文件夹；
3. 在同目录放一个同名 `.md`，写几条本次更新要点（推荐，店员看得懂）；
4. 手机端「设置 → 软件更新」点「检查更新」即可看到。

> 文件名里**必须带版本号**，否则手机端会忽略这个文件。

### 让所有手机必须更新（版本收口）

「系统设置 → 强制更新」里勾选手机包 `.apk` 保存即可。手机端的宽限期规则：

- **24 小时**内、或店员**推迟 3 次**以内（谁先到算谁），可以点「稍后再说」，每次打开 App 都会再提醒；
- 超过后才会强制拦截：店员**没法跳过更新**，但可以点「立即更新」装上新版，或点「**退出应用**」先收工。点「退出应用」会再问一次「确定要退出吗？」（提示：退出后仍需重新打开本应用才能继续拍照），确认后回到手机桌面，不会丢任何照片；下次打开 App 会接着提醒，直到更新完成。

### 桌面端与手机端的版本号顺序

**这一版起，桌面端已经不会把手机安装包误当成自己的更新推给电脑用户了。**

以前桌面端挑更新包是「看更新目录里版本号最高的那个文件」，不区分电脑包和手机包——手机端版本号一旦涨过桌面端，桌面端就会拿手机包装去提示电脑用户升级。现在这道判断里加了过滤：**更新目录里的手机安装包一律跳过**，所以无论两边版本号怎么交错，桌面端都只看得到电脑安装包。

因此不再需要人工死守「桌面端版本号必须高于手机端」这条约定。不过仍**建议**保持桌面端版本号高于手机端：一眼能看清两边谁新，也避免别的理解偏差。**违反了也不会造成误推送。**

## 三、已知限制

### 1. 桌面端版本不能低于 v1.2.4

移动端 v1.1.0 的更新功能依赖本版新增的接口。**桌面端低于 v1.2.4 时，手机端会「检测不到任何更新」** —— 不报错、不提示，就是没反应。手机端手动点「检查更新」会提示「这台服务器的桌面端版本较旧」，据此可以判断。

**升级顺序建议：先升桌面端，再让店员更新手机。**

### 2. 手机端不做后台静默下载

发现新版本只弹窗，必须店员本人在手机上点「立即更新」才下载。这是为了避免门店几十台手机同时自动下载打满 WiFi。

### 3. 更新说明只支持两种写法

- 同名 `.md` 文件（推荐）；
- 或同名 `.json` 文件里的 `notes` 字段（为将来结构化预留）。

两种都没有时手机端显示兜底文案。桌面端界面上暂时**没有**编辑更新说明的输入框，仍需手工建文件。

### 4. 手机端下载是整包下载，无断点续传

中途断网需要从头重下（门店 WiFi 下一般几十秒到几分钟）。断网后手机端会自动重试 3 次。

### 5. 校验值与安全边界的现状

- 手机安装包在服务器上会做完整性校验（大小、指纹），但**两者都取不到时不会因此卡住更新** —— 这是刻意的取舍，优先保证店员能用上；
- **门店网络是明文的**，安全边界由「门店 WiFi + 连接码」承担。本版没有引入 HTTPS 证书。如果将来要放到不可信网络里用，需要单独立项。

## 四、兼容性

| 客户端 | 最低要求 | 说明 |
|---|---|---|
| 桌面端 | —— | 本版即 v1.2.4 |
| 移动端 Android | v1.0.0 | 低于 v1.0.0 未支持在线更新 |
| 移动端 + 本桌面端 | 桌面端 ≥ v1.2.4 | 低于此版本手机端无法在线更新 |
| 桌面端 + 老桌面端服务端 | 无影响 | 本版改动完全向后兼容，未升级的门店不受影响 |

- **已装 v1.2.3 可直接覆盖升级**，配置与数据不丢失；
- 本版给桌面端原有的更新检查加了一条过滤：**更新目录里的手机安装包（`.apk`）会被忽略**，所以桌面端不会再把手机包装误判成电脑更新。接口对外的响应字段与返回结构没有变化，未升级的门店不受影响。

## 五、安装

双击 `xingqiyi-laundry-photo-setup-1.2.4.exe`，按向导完成安装（可自选目录）。安装包内置全部运行环境，目标电脑无需安装 Node.js。

安装包 SHA-256 校验值见发布附件 `SHA256SUMS.txt`。
