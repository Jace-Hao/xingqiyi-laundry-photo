**一句话**：本版是**安全修复版**——修掉三个会导致「照片在用户看不见确认提示的情况下被删除」的严重缺陷，并补齐了键盘可达性。

## 一、本版修掉的严重缺陷（建议所有门店尽快升级）

### 1. 灯箱里删除记录时，确认弹窗被完全遮挡（最高优先级）

**现象**：在「记录查询」里点开一条记录进入大图预览（灯箱），再点「删除记录」——**确认弹窗被大图预览整层盖住，用户什么都看不到**。

**危险之处**：此时按 Enter 键，删除**照常执行**。用户从未见过任何确认提示，照片已经被删掉。更糟的是，用户因为看不见弹窗，会去点灯箱里的其它按钮，灯箱一关闭弹窗才露出来——但这时记录已经被删了。这是一条「看不见的破坏性操作」。

**修复**：把确认弹窗的层级提到高于大图预览。**一条样式改动，修复了全部三个弹窗**（删除确认、改条码、批量改码）。

### 2. 危险操作的确认弹窗，按 Enter 会误删

**现象**：删除类弹窗已经把焦点默认放在「取消」按钮上（防误触），但按 Enter 键**仍然会执行删除**。用户看到焦点框在「取消」上，按 Enter 却真的删了——**看到的提示和实际行为不一致**，比不做防误触更危险。

**修复**：Enter 键现在遵循「激活当前焦点按钮」的语义——焦点在取消上按 Enter 是取消，焦点在确认上按 Enter 才执行删除。同时补上了中文输入法保护：在输入框打字时按 Enter 选词，不会再触发弹窗按钮。

### 3. 键盘用户无法使用主要功能

**现象**：记录卡片和左侧导航都是只能用鼠标点的元素，**完全无法用键盘操作**。这意味着「查询 → 打开记录 → 下载原片」这条主流程，纯键盘用户一步也走不了。

**修复**：记录卡片和导航项现在都能用 Tab 键选中、Enter/空格键打开，并补上了可见的焦点框与读屏语义。

### 4. 弹窗打开时，背景内容仍可被键盘操作

**现象**：确认弹窗弹出后，Tab 键仍能走到弹窗背后的内容上，键盘用户会「迷失」。

**修复**：弹窗打开时背景自动进入不可交互状态，关闭后恢复。

## 二、其他改进

| 改进点 | 说明 |
|---|---|
| **导出按钮不再串台** | 此前点「按订单号批量下载」，另外两个按钮会一起变灰、且「下载原片」按钮显示「下载中…」，用户无法判断哪个操作在进行。现在每个按钮只显示自己的状态 |
| **批量删除确认显示条码** | 删除多条记录时，确认弹窗会列出前 3 个条码供核对，避免删错。仅选 1 条时不再有多余的「等共 1 条」字样 |
| **快速连点不再丢失操作** | 确认弹窗期间导出按钮会置灰，防止连点导致前一个操作被静默丢弃 |
| **本周订单可跳转处理** | 「本周订单」页的条码现在可以直接点击，跳转到记录查询并自动带入条码——不用再记下条码手动重输 |
| **暗色模式不再发白** | 登录页、启动页背景与各类提示条改为跟随主题。深色偏好用户打开应用第一眼不再是一块刺眼的浅蓝 |
| **导出按钮文案更清楚** | 「按订单号批量下载」→「导出照片 + 清单表」，「下载原片（按文件夹）」→「只下载原片（无清单）」。两个按钮的真实区别一直存在但没说清，现在写在标题里了 |
| **改码弹窗标题正常显示** | 改条码弹窗的标题此前没有任何样式，退化成普通文字，且缺少关闭按钮。现在与其它弹窗一致，并有明确的 ✕ 关闭键 |
| **侧栏窄窗口文字竖排** | 窗口宽度 ≤1023px 时侧栏自动收窄，此前「收起侧栏」「外观」等文字会竖排挤成一列溢出，已修 |

## 三、这次是怎么验证的

本版所有修复**不是只靠读代码判断**，而是在真实运行的桌面应用上逐条实测：

- 「灯箱内点删除记录」走完整链路，并把层级临时调回修复前的状态，**复现了原本看不见弹窗的问题**，再恢复确认修复有效；
- 中文输入法组合态、危险弹窗 Enter 分支、弹窗遮挡、背景不可交互，均在真实按键事件下验证；
- 每条修复都配了**反向对照**（临时还原成有 bug 的版本，确认测试确实会失败），确保「通过」不是因为方法失灵；
- 自动化校验全部通过：模板引用、摄像头、水印、缩略图、凭据、门店、用户权限、服务端、发布隔离。

## 四、兼容性

- **移动端保持 v1.1.0，不需要联动升级**：本版只改动桌面端界面与交互，未改动任何对外 HTTP 接口与数据格式。
- **已装 v1.2.7 可直接覆盖升级**，配置与照片数据不丢失。
- **已装更早版本**同样可直接覆盖安装到 v1.2.8。

## 五、管理员操作指南（验证与回滚）

### 升级后建议这样验证

1. 覆盖安装 `xingqiyi-laundry-photo-setup-1.2.8.exe`；
2. **重点验证第 1 条**：记录查询 → 点开一条记录 → 点「删除记录」→ 确认弹窗应**清晰可见**；此时按 Enter 应**不删除**（焦点默认在「取消」）→ 再点「删除」才会删除；
3. 用 Tab 键试着在记录卡片和左侧导航间移动，应能看到焦点框，按 Enter 能打开；
4. 侧栏底部切换一次深色外观，登录页与提示条应**不再发白**。

### 回滚

若发现异常，覆盖安装上一版 `xingqiyi-laundry-photo-setup-1.2.7.exe` 即可。**必须整包覆盖安装，不要只替换单个文件**。

## 六、安装

双击 `xingqiyi-laundry-photo-setup-1.2.8.exe`，按向导完成安装（可自选目录）。安装包内置全部运行环境，目标电脑无需安装 Node.js。

安装包 SHA-256 校验值由发布流程自动生成，见发布附件 `SHA256SUMS.txt`。

## 七、已知未修（下一版处理）

- **同一时刻只允许一个确认弹窗**：若在极短时间内连续触发两个不同的确认弹窗，前一个会被后一个顶掉、其操作静默失效（导出类已加保护，其他如单条删除、改码仍有此隐患）。
- 灯箱打开后焦点未自动移入、关闭后未还原。
- 左侧「本周订单」等新功能**尚未补入手册图文说明**（侧栏可直接看到入口，功能可正常使用）。
