# 桌面端 v1.2.5 发布说明

**一句话**：本版修掉了「拍照时预览间歇性黑屏、必须手动重开摄像头才能恢复」的问题，并补齐了关键路径日志，便于现场定位。

| 项目 | 值 |
|---|---|
| 版本 | v1.2.5 |
| 配套 | 移动端 **v1.1.0**（无需联动升级） |
| 上一版 | v1.2.4 |

---

## 一、本版修了什么

### 拍照后预览黑屏（核心修复）

之前在拍照、切换摄像头、退后台再回前台等场景下，预览窗口会间歇性变黑，且没有任何报错，店员只能退出重开摄像头甚至重启软件。根因有四类叠加：

1. **摄像头资源/生命周期未受控**：取流期间页面切走、或短时间内多次触发开摄像头，旧的摄像头流没有被正确释放，导致句柄泄漏或被新流覆盖，再开预览就取不到画面；
2. **摄像头被抢占/松动后无感知**：系统相机 App 抢占、USB 松动、休眠唤醒后，摄像头轨道其实已经失效，但软件仍显示黑画面，并且会在这种情况下把纯黑照片拍进档案（数据污染）；
3. **错误被界面吞掉**：部分情况下播放失败或取景框未就绪，界面既不显示画面也不显示任何错误提示，就是一片黑；
4. **部分摄像头 `play()`/`applyConstraints()` 永不返回**：控制器会永久停在「准备中」，同样只能手动重开。

本版引入了一个摄像头预览状态机（取流令牌守卫 + 单一活跃流 + 自动重连 + 超时兜底）：

- 任意时刻最多只有一条活跃摄像头流，离屏/卸载/重复打开都会自动回收旧流，不再泄漏；
- 摄像头轨道被抢占、静音、结束都会自动重连，无需店员手动干预；
- 反复闪断（30 秒内连续 6 次）会停止自动重连并提示「重试」，避免重连风暴；
- 取景框播放/分辨率协商/权限预检都加了超时，不会再无限期卡死；
- 纯黑帧会被识别并拒绝拍照入库，避免污染档案（深色衣物极端暗光下若被误拦，可在现场用 `window.__xqyBlackFrame=false` 临时关闭该检测）。

### 权限引导

若系统层面未授予摄像头权限，界面会直接给出「去系统设置开启摄像头」的入口（Windows 下点击跳转隐私设置页，其它平台给出文字引导）。

### 摄像头诊断日志

新增 `<userData>/logs/camera-YYYYMMDD.log`（单行 JSON，2MB 轮转、保留 7 天）。现场出现取流异常时，运维可直接看日志定位：泄漏证据（`CAM_LEAK_GUARD`）、权限链路（`CAM_PERMISSION_CHECK`）、出画/休眠/唤醒（`CAM_LIVE`/`CAM_SLEEP`/`CAM_WAKE`）、窗口可见性（`CAM_WINDOW_STATE`）等。日志不会写满磁盘，也不影响拍照主流程。

## 二、兼容性

- **移动端保持 v1.1.0，不需要联动升级**：本版未改动任何对外 HTTP 接口与数据结构，移动端依赖的桌面端接口自 v1.2.4 起即已具备。
- **已装 v1.2.4 / v1.2.3 可直接覆盖升级**，配置与照片数据不丢失。
- 升级后无需清数据；新增的 `logs/` 目录不影响既有数据，7 天后自动清理。

## 三、管理员操作指南（验证与回滚）

### 上线后建议先灰度 1 台

1. 在 1 台多摄像头机器 + 1 台 USB 摄像头机器上，按现场走查表跑一遍：进页即切走再回、系统相机 App 抢占、拔插 USB、托盘隐藏再唤出、锁屏解锁、连续拍照/连拍、捂镜头、关闭系统相机隐私开关后启动；
2. 确认黑屏不再复现、异常能自动恢复、拍照正常、日志目录有产出；
3. 跑满 1 个营业日后再全量推送。

### 现场排查入口

- 程序内 `window.api.cameraLogPath()` 可取日志路径；
- 日志默认位于用户数据目录下的 `logs/camera-YYYYMMDD.log`。

### 回滚

若发现完全不出画且重启无效、拍出黑照片入库、启动即崩溃、或非拍照功能受影响，直接覆盖安装 `xingqiyi-laundry-photo-setup-1.2.4.exe` 即可。**必须整包覆盖安装，不要只替换单个文件**（本版是主进程/渲染层/模板/样式的一组协同改动，只回退单个文件会造成半吊子状态）。回滚前请先备份 `logs/` 目录作为复盘证据。

## 四、已知限制

1. 黑屏复现为间歇/概率性，自动化只能验证纯逻辑，真机复现依赖现场硬件；已在多摄像头机 + USB 机上走查。
2. 黑帧检测阈值极苛刻，深色衣物在极暗光下仍存在理论误判可能（已留一键关闭）。
3. 若门店摄像头质量极差、持续闪断超过阈值，软件会停止自动重连并提示人工「重试」，属预期行为而非缺陷。

## 五、安装

双击 `xingqiyi-laundry-photo-setup-1.2.5.exe`，按向导完成安装（可自选目录）。安装包内置全部运行环境，目标电脑无需安装 Node.js。

安装包 SHA-256 校验值见发布附件 `SHA256SUMS.txt`。
