# v1.2.21 更新说明

## 缺陷修复
- **修复调整后空格无法拍照**：之前在调整亮度滑块后，滑块仍保持焦点，必须点击空白处使其失焦后才能用空格拍照。现已改为全局空格拍照——只要焦点位于软件窗口内（亮度滑块、下拉、按钮、条码框、页面空白等任意区域），按下空格即触发拍照，不再依赖某个特定控件是否获得焦点。
- 备注、搜索等自由文本输入框内的空格仍按原生输入处理，不影响正常打字；输入法组合态（拼音选字）照常放行，不打断候选确认。
