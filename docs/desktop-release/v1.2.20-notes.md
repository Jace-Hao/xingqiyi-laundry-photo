# 星期衣精致洗衣衣物照片系统 v1.2.20 发布说明

## 新增功能
1. **扫码成功自动亮度校准**：每次成功识别条形码后，自动采样当前预览帧亮度并将摄像头原生亮度推近中灰目标，补偿不同衣物 / 光线下预览过暗或过亮。仅本次会话生效，不覆盖已保存的亮度偏好，校准不理想时可随时用手动亮度滑块微调。
2. **预览点击重新对焦**：点击相机预览画面任意位置触发一次单点对焦（点哪对焦哪；设备不支持坐标对焦时回退中心对焦），对焦完成后自动恢复连续对焦。点击以「保留输入框焦点」方式处理，不会打断扫码枪输入流程。

## 兼容性
- 设备不支持 `brightness` 能力时，自动校准与亮度滑块整体不生效，不影响正常拍摄。
- 设备不支持 `pointsOfInterest` / `single-shot` 对焦时，点击对焦静默忽略，不影响扫码。
