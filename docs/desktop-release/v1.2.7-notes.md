# 桌面端 v1.2.7 发布说明

**一句话**：本次是「体验 + 效率」双线更新——把整套界面按设计系统 v2 重做（统一令牌、双主题、体系化组件），并补齐两项长期缺的能力：照片原片下载（单张 / 批量，后端直出）和「本周订单」独立侧栏页面。

| 项目 | 值 |
|---|---|
| 版本 | v1.2.7 |
| 配套 | 移动端 **v1.1.0**（无需联动升级） |
| 上一版 | v1.2.6 |

---

## 一、本版新增 / 改了什么

### 1. UI 设计系统 v2 重做

把此前零散的样式收敛为一套统一的设计令牌（颜色 / 间距 / 圆角 / 字体 / 阴影），并落地为 CSS 变量驱动的明亮 + 暗色双主题。具体变化：

- **设计令牌体系化**：背景 / 前景 / 卡片 / 分割线 / 主色等全部抽成 `--bg`、`--text`、`--text-sub`、`--card`、`--divider`、`--primary` 等变量，明暗两套配色集中管理，切换主题不再逐处改色值。
- **信息层级与容器**：卡片、表格、侧栏导航、页头等形成一致的视觉层级；主内容区限定最大宽度（`max-width: 1440px`）居中，大屏不再无限拉伸。
- **组件统一**：按钮（主 / 次 / 幽灵、尺寸 sm/md）、确认弹窗、空状态 / 加载态 / 错误态等补齐并复用，交互反馈更一致。
- **操作手册同步**：随版本号提升同步更新 `docs/manual.md` 标题与版本行，避免应用内「手册版本不匹配」提示。

> 本次重做**不改变任何业务功能与数据**，纯视觉与组件层重构，已通过 `verify-manual-render` 等自检。

### 2. 照片原片下载（后端直出，新增能力）

此前查询页只能「在线预览 / 按日期导出清单」，取原片要走导出流程。本版新增**直接下载原始照片**入口，且由后端按原文件名落地，避免二次压缩或改名：

- **单张下载**：查询页灯箱（大图预览）面板新增「下载原片」按钮 → 选择目标目录 → 后端 `store.downloadPhoto` 按原始文件名（`photoFile` 原名）拷贝到所选目录，并记一条 `下载原片` 操作日志。
- **批量下载（按文件夹）**：查询页批量工具条新增「⬇ 下载原片（按文件夹）」→ 先确认 → 选择目录 → 后端 `store.downloadPhotos` 按**条码分文件夹**，文件名形如 `2026-10-08_14-30-05_第1张.jpg`（拍摄时间 + 序号 + 原扩展名），并记一条 `批量下载原片` 日志。**不生成 CSV 清单**（与「按日期导出」区分：导出带清单，下载只要原片）。
- **双模式兼容**：
  - 服务端模式：直接本地拷贝照片文件（`store.resolvePhotoFile` 带路径穿越防护）。
  - 客户端模式：`main.js` 的 `clientDownloadPhoto(s)` 通过既有 `GET /photo?f=<file>&token=<token>` 接口带令牌拉取，再写入本地，逻辑与既有 `clientExportPhotosByDate` 一致。
- **权限**：沿用查询权限（`requireSessionPermission(token,'query')` + 门店 / 角色可见范围），越权条码自动跳过。

### 3. 「本周订单」独立侧栏页面（新增）

新增只读汇总页「本周订单」，挂在侧栏「门店」分组下，**三个角色（系统管理员 / 门店管理员 / 普通账号）均可见**：

- **时间口径**：「本周」= 以今天为终点、向前滚动 **7 天**（含今天）的窗口（`dateFrom = 今天-6天`, `dateTo = 今天`），非自然周，门店每天看的是「最近 7 天」连续数据。
- **聚合维度**：按衣物条形码（订单号）聚合，每行展示：照片张数、首拍时间、末拍时间、录入人（同条码多录入人合并）、所属门店。
- **只读、无导出**：该页只做汇总查看，**不提供任何文件导出 / 下载**——防止误触在大目录下生成大量文件；需要原片请回到查询页用上面的「下载原片」功能。
- **性能**：分页拉取（每页 100，最多 5 页 / 500 单）后在本地聚合，带加载态 / 空态 / 错误态。

## 二、兼容性

- **移动端保持 v1.1.0，不需要联动升级**：本版未改动任何对外 HTTP 接口与数据结构。
- **新增的下载能力是桌面端本地 IPC + 后端函数**：`records:downloadPhoto` / `records:downloadPhotos` 为本地进程间调用（服务端模式走 `store.*`，客户端模式走既有 `/photo` 接口），**不新增对外 HTTP 端点**，不影响移动端或老服务端。
- **已装 v1.2.6 可直接覆盖升级**，配置与照片数据不丢失；升级后界面即变为设计系统 v2 样式，并出现「下载原片」与「本周订单」入口。
- **已装 v1.2.5 及以下版本**同样可直接覆盖安装到 v1.2.7。

## 三、管理员操作指南（验证与回滚）

### 上线后验证

1. 覆盖安装 `xingqiyi-laundry-photo-setup-1.2.7.exe`；
2. 启动后确认：
   - 界面已切换为 v2 视觉（令牌化配色、统一卡片 / 按钮 / 弹窗）；
   - 查询页灯箱出现「下载原片」、批量条出现「⬇ 下载原片（按文件夹）」，分别能按原文件名 / 按条码分目录落盘；
   - 侧栏「门店」分组下出现「本周订单」，打开是近 7 天按条码聚合的只读表格；
   - 操作日志中能看到 `下载原片` / `批量下载原片` 记录。
3. 若界面出现「手册版本不匹配」提示，说明 `docs/manual.md` 版本行未同步——本版已同步，正常不会出现。

### 回滚

若发现异常（如主题切换异常、下载落盘路径不符预期、或旧功能受影响），直接覆盖安装上一稳定版 `xingqiyi-laundry-photo-setup-1.2.6.exe` 即可。**必须整包覆盖安装，不要只替换单个文件**。

## 四、安装

双击 `xingqiyi-laundry-photo-setup-1.2.7.exe`，按向导完成安装（可自选目录）。安装包内置全部运行环境，目标电脑无需安装 Node.js。

安装包 SHA-256 由发布脚本在发布时计算并打印在发布日志中，用于人工核对（发布后可在 Release 说明或发布日志查看）。
