# v1.2.22 更新说明

## 新增功能

- **新增「会员订单」页，可导入会员导出软件的订单数据**：左侧菜单新增「会员订单」入口（系统管理员、门店管理员、拍照账号、查询账号均可见）。支持读取或导入第三方会员 / CRM 导出软件导出的 CSV、JSON 文件，自动解析**订单号、会员姓名、会员手机、商品名称、订单金额、下单时间、订单状态**等关键字段，并映射到本系统订单模型——**订单号即条形码**，可直接在「衣物拍照」页据此建档，省去手工誊抄。
- **导入前可预览，确认无误再入库**：点「选择文件并预览」后，先展示解析结果再决定是否导入。预览区含三张统计卡（可导入订单 / 库内已存在 / 无效与文件内重复）、逐行的字段映射表，以及「字段缺失与格式异常」清单（逐条标注行号、字段与原因，便于回查源文件）。
- **重复订单不覆盖**：订单号与库内已有记录重复时默认跳过，不覆盖原有数据；同一文件内的重复行只保留第一条。订单号比对不区分大小写。若订单号已存在同名条码的照片存档，仅作提示，不影响导入。
- **字段缺失与格式异常可容错**：金额、时间、会员信息缺失或格式异常时，该条订单仍会导入，缺失项留空并在异常清单中提示——金额不会用 0 冒充有效值。源文件中未被识别的列会一并保留，便于人工回查。
- **表头智能识别**：不同导出软件的表头写法不一，系统按别名表自动匹配（订单号 / 会员姓名 / 手机 / 商品 / 金额 / 时间 / 状态等常见写法均可识别）；源文件没有表头时按内容特征推断列位，并在预览中提示需人工核对。

## 权限与安全

- 导入需「衣物拍照」权限（拍照账号与系统管理员）；门店管理员与查询账号可查看已导入的会员订单，但不能导入。导入与删除操作均记入操作日志。
- 会员订单独立存储，不与照片存档混存，因此不会影响照片列表、统计口径与照片保留期清理策略。
